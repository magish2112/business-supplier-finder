# 🔍 Улучшенный поиск бизнес-поставщиков v2.3

Веб-приложение для поиска производителей, дистрибьюторов и крупных поставщиков строительных материалов с безналичной оплатой и быстрой доставкой.

**🚀 Новое в версии 2.3:** Расширенный поиск по 15+ источникам для максимального охвата поставщиков!

## 🤖 Perplexity AI Integration (v2.2)

### 🎯 **AI-powered поиск поставщиков**
- **Интеллектуальный анализ** - Perplexity AI понимает контекст бизнес-запросов
- **Качественные результаты** - фокус на проверенных компаниях с хорошей репутацией
- **Структурированные данные** - автоматическое извлечение контактной информации
- **Высокий рейтинг** - AI-генерированные результаты имеют повышенный рейтинг релевантности

### Проблемы с Perplexity API

Если Perplexity API не работает:

```bash
# Проверьте наличие API ключа
echo $PERPLEXITY_API_KEY

# Проверьте доступность OpenAI библиотеки
python -c "from openai import OpenAI; print('OpenAI OK')"

# Проверьте подключение к Perplexity
python -c "
from openai import OpenAI
client = OpenAI(api_key='your_key', base_url='https://api.perplexity.ai')
print('Perplexity connection OK')
"
```

**Решения:**
- Установите `openai>=1.0.0`
- Добавьте `PERPLEXITY_API_KEY` в `.env`
- Установите `PERPLEXITY_ENABLED=true`
- Проверьте интернет-соединение

## ⚙️ Конфигурация

### Основные настройки (.env)

- `SECRET_KEY` - секретный ключ Flask (обязательно изменить в продакшене)
- `FLASK_DEBUG` - режим отладки (True/False)
- `FLASK_HOST` - хост для запуска (по умолчанию 0.0.0.0)
- `FLASK_PORT` - порт для запуска (по умолчанию 5000)

### Настройки парсера

- `DELAY_BETWEEN_REQUESTS` - задержка между запросами (секунды)
- `MAX_RETRIES` - максимальное количество попыток
- `REQUEST_TIMEOUT` - таймаут запросов
- `MAX_CONCURRENT_REQUESTS` - максимум одновременных запросов

## 📊 Формат результатов

Каждый поставщик теперь содержит расширенную информацию:

### Основная информация
- **Название компании**
- **Тип компании** (Производитель/Дистрибьютор/Оптовый поставщик/Склад)
- **Размер компании** (Крупная/Средняя/Маленькая)
- **Телефон** (кликабельный)
- **Email** (кликабельный)
- **Сайт** (кликабельный)

### Аналитические данные
- **Релевантность** (0-100) - комплексная оценка соответствия запросу
- **Полнота контактов** (%) - процент заполненности контактных данных
- **Бизнес-индикаторы** - ключевые слова, подтверждающие тип бизнеса
- **Источник** (Google/Yandex/B2B-площадки)
- **Описание** (если доступно)

### Система скоринга
Компании ранжируются по комплексному алгоритму:
1. **Тип компании** (производители получают максимальный приоритет)
2. **Релевантность поисковому запросу**
3. **Качество и полнота контактов**
4. **Региональное соответствие**
