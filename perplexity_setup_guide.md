# 🚀 Быстрая настройка Perplexity AI для поиска поставщиков

## 1. Получение API ключа

1. Перейдите на [https://www.perplexity.ai/settings/api](https://www.perplexity.ai/settings/api)
2. Зарегистрируйтесь или войдите в аккаунт
3. Создайте новый API ключ
4. Скопируйте ключ

## 2. Настройка .env файла

Создайте или обновите файл `.env`:

```bash
# Добавьте эти строки:
PERPLEXITY_API_KEY=your_actual_api_key_here
PERPLEXITY_ENABLED=true
```

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 4. Тестирование

```bash
# Проверьте работу Perplexity API
python test_perplexity_api.py
```

## 5. Запуск приложения

```bash
python web_app.py
```

## ✅ Что изменится

После настройки Perplexity AI:

- 🤖 **Умный поиск** - AI понимает бизнес-запросы лучше
- 🎯 **Точные результаты** - фокус на проверенных компаниях
- 📞 **Полные контакты** - автоматическое извлечение телефонов, email, сайтов
- ⭐ **Высокий рейтинг** - AI-результаты получают приоритет
- 🚀 **Быстрее** - меньше мусорных результатов

## 🔧 Дополнительные настройки

```bash
# В .env файле можно настроить:
PERPLEXITY_MODEL=sonar-pro          # Модель AI
PERPLEXITY_MAX_TOKENS=2048          # Максимум токенов
PERPLEXITY_TEMPERATURE=0.1          # Креативность (0.1 = точные ответы)
PERPLEXITY_SEARCH_TIMEOUT=30        # Таймаут запроса
PERPLEXITY_MAX_RESULTS=10           # Максимум результатов
```

## 🛠️ Устранение проблем

Если что-то не работает:

```bash
# Проверьте API ключ
python -c "import os; print('Ключ:', bool(os.getenv('PERPLEXITY_API_KEY')))"

# Проверьте подключение
python test_perplexity_api.py
```

## 💡 Советы по использованию

1. **Без API ключа** - приложение работает в обычном режиме
2. **С API ключом** - поиск становится умнее и точнее
3. **Тестируйте** - используйте `test_perplexity_api.py` для проверки
4. **Мониторьте логи** - смотрите логи для отладки
